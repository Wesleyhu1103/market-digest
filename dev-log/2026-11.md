# Dev log — November 2026

## 2026-11-13 — Static deploys no longer apply leftover incoming digests
- What: `publish-digest.yml` now skips `publish_digest.py` when the plan is static-only; added a workflow regression test.
- Why: a stale committed `incoming/new-main.html` could be applied during an unrelated docs/API deploy and overwrite the live digest.
- Gotcha: incoming digest pushes still run with `static=false`, so intentional daily publishes are unaffected.
