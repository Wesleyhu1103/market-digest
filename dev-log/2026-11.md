# Dev log — November 2026

## 2026-11-12 — Static deploys skip digest splice
- What: `publish-digest.yml` now guards the `publish_digest.py` apply step with `needs.plan.outputs.static != 'true'`, with a regression test pinning the guard.
- Why: a static-only docs/API/workflow push should deploy assets only; if a stale committed `incoming/new-main.html` is present, running the splice step can overwrite the live digest outside the intentional incoming path.
- Gotcha: static deploys still run contract/index validation and deploy Pages/Vercel; they just cannot archive/splice daily content.
