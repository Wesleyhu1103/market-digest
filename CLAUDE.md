Project context, local commands, and gotchas live in [AGENTS.md](AGENTS.md) — read that first.

## Dev log (required)

After completing any fix or feature in this repo, append a short entry to
`dev-log/YYYY-MM.md` (create the file for a new month using the format in
`dev-log/README.md`). Each entry is 2–3 lines:

- **Date + what changed** (one line)
- **Why** (one line)
- **Gotchas**, if any (one line, omit if none)

Keep entries terse — this is a memory aid read in Obsidian, not documentation.
Do not create or edit any daily market notes; those are written by hand.
